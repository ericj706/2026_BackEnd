
[ 자바 실행 순서 ]
    1. src폴더내 .java 확장자에서 java 코드 작성
    2. 빌드(build) : run java 실행
    3. [컴파일] bin 폴더내 .class 확장자 파일 (자동)생성
[ 주석 ]
    1. // 한줄 주석
    2. /*  */ 여러줄 주석
[ 용어 ]
    1. package : 해당 클래스가 위치한 폴더명
    2. class : 자바에서 컴파일 하는 최소의 단위 *클래스{} 안에서 코드 작성*
    3. main함수 : 자바에서 코드 실행하는 흐름 = 스레드 제공
    4. ;세미콜론 : 코드의 한문장 마침 뜻
[ 자료 ] : 데이터
    1. 리터럴 : 상수
    2. 자료타입(형)
        (1) boolean 1byte   true/false
        (2) char    2byte   ''감싼 문자1개저장
        (3) byte    1byte   +-128
        (4) short   2byte   +-3만
        (5) int     4byte   +-21억      *정수 리터럴 기본타입*
        (6) long    8byte   +-21억이상,  L/l
        (7) float   4byte   소수점 8자리 표현,  F/f
        (8) double  8byte   소수점 17자리 표현,   *실수 리터럴 기본타입*
        (*) String  N*2byte ""감싼 문자N개저장,  문자열객체(배열)

[ 출력함수 ]
    1. System.out.print();    : 출력
    2. System.out.println();  : 출력+줄바꿈
    3. System.out.printf("형식문자", 자료); : 형식문자
    ** 이스케이프/제어 문자: \n(줄바꿈) \t \' \" \\
    ** gudtlranswk : %s문자열 %d정수 %c문자 %f실수 , %자릿수s %-자릿수s %0자릿수s %전체자릿수.소수점자릿수f
[ 입력함수 ] : 다양한 입력방식 제공.
    1. 입력객체 생성 (클래스마다 1번씩)
        Scanner scan = new Scanner(System.in);
    2. 입력객체 통한 입력함수 ( nextXXX(), 타입 주의, 엔터기준으로 구분)
        타입 변수명 = scan.nextXXX();


[ 타변변환 ]
    * 다형성 : (하나의 자료/값) 다양한 형태(타입) 갖는 성질
    1) 자동타입변환 : byte -> short -> int -> long -> float -> double , * 연산 결과 *
    2) 강제타입변환 : double -> float -> long -> int -> short -> byte , (변환할타입명)자료

[ 연산자 ]
    1. 산술연산자: + - * / %
    2. 연결연산자: +
    3. 비교연산자: > < >= <= == !=
    4. 논리연산자: && || !
    5. 증감연산자: ++변수명 , 변수명++ , --변수명 , 변수명--
    6. 대입연산자: =  , 복합대입연산자: +=  -=  *=  /=  %=
    7. 삼항연산자: 조건 ? 참 : 거짓  , 중첩:  조건1 ? 참1 : 조건2 ? 참2 : 거짓  -> 참/거짓 
    * 문자열비교함수: 문자열A.equals( 문자열B )

[ 조건문 ] 조건에 따른 코드 흐름 제어 
    1. if( 조건 ) 실행문;
    2. if( 조건 ){ 실행문; 실행문; }
    3. if( 조건 ){ } else{ }
    4. if( 조건 ){ } else if( 조건 ){ } else if( 조건 ){ } else { }
    5.  switch( 자료 ){
            case 값1: 실행문; break;
            case 값2: 실행문; break;
            case 값3: 실행문; break;
            default: 실행문;
        }

[ 반복문 ] 조건에 따른 코드 반복 제어 
    1. for( 초기식 ; 조건식 ; 증감식 ){ }
    * break; continue;
    2. 초기식; while( 조건식 ){ 증감식;  }
    3. for( 타입 변수명 : 배열 ){ }
    * 배열타입이 int 이면 왼쪽 변수 타입도 int 맞춘다.

[ 배열 ] *동일한타입*의 여러 자료들을 *하나의* 배열타입 저장
    1. 선언 : 
        1) 타입[ ] 변수명 = new 타입[개수] 
        2) 타입[ ] 변수명 = { 값1, 값2, 값3 }
    2. 특징 : 
        1) 동일한타입끼리 
        2) 정적(고정)길이 
        3) 초기값이 없으면 기본값할당( 정수:0, 실수:0.0, 논리:false, 객체:null )
    3. 호출 : 
        1) 배열변수                     : 배열의 주소값 반환 , I@4517d9a3 출력
        2) Arrays.toString( 배열변수 )  : 배열의 요소들을 문자열 반환 , [ ] 출력
        3) 배열변수[인덱스]              : 배열내 특정한 인덱스의 요소값 반환 
        * 인덱스란? 배열내 요소들이 저장된 순서번호(0~)
    4. 요소값수정: 배열변수[인덱스] = 새로운값
        * 요소삭제없음,요소추가없음 
    
[ 객체 ] 객체지향 프로그래밍
    1.정의 : 상태(멤버변수/필드/속성) 와 행위(메소드/함수) (추상)정의 하는 것 
    2.클래스 : 상태와 행위 코드로 작성(설계도)
        -> 용도: 1)설계 2)실행(main함수갖는)
    3.인스턴스 : 특정 클래스로 생성(new)한 객체(실체)
    4.사용법
        1) 클래스 생성 
            - class 클래스명{ 멤버변수; 생성자; 메소드; }
            - 멤버변수: 
                타입 변수명;                   *만일 초기값이 없으면 기본값*( 정수:0, 실수:0.0, 논리:false, 객체:null )
                타입 변수명 = 초기값;
        2) 인스턴스 생성 
            - new 생성자명( );                 * new 1개당 인스턴스 1개 생성(즉 메모리 주소값 생성)*
            - 타입 변수명 = new 생성자명( );
        3) 인스턴스 참조
            - 객체변수명.멤버변수명;            * .(접근/도트)연산자 : 변수가 갖는 객체의 주소로 이동(포인터) *
            - null : 변수가 null 이면 이동할주소(참조할객체)가 없다.
    *) 객체는 변수가 참조하지 않으면 자동 사라진다. ( GC )


[지역,멤버,매개 변수]
선언되는 변수 위치에 따라 이름이 다르다.
    지역변수: if/for/func(){} '안에서' 선언된 변수
    멤버변수: 클래스/설계도{} '안에서' 선언되고 객체(인스턴스)내 변수
            this: 해당 생성자/메소드 호출한 객체(인스턴스)가리킴
    매개변수: 생성자/메소드 호출하면서 인수값들을 저장하는 변수

[ 생성자 ]
    (1) 인스턴스(객체) 생성할 때 초기화 담당
        - new 생성자명( )
    (2) 사용법
        1. 클래스 내부 선언     2. 클래스명 동일    3. 반환타입 없다    
        4. 오버로딩 지원( 동일한 이름의 서로 다른 매개변수의 개수/타입/순서 다르면 중복)
    (3) 목적: 객체생성시 초기화, 협업간의 규칙/유효성검사
    (4) 주의할점: 정의한 클래스내 생성자가 1개도 없으면 기본생성자 (자동) 제공
    (5) this 키워드:

[ 메소드 / 함수 ]
    1. 자바 클래스 내부 선언
    2. 목적: 코드의재사용, 인수에 따른 서로 결과물 반환
    3. 선언
        접근제한자 반환타입 메소드명( 타입 매개변수 ){
            실행문;
            return 반환값;
        }
        - 반환타입: return에 반환할 값의 타입 없으면 void
        - 매개변수: 메소드 호출시 전달되는 인수/인자 값 저장하는 변수
    4. 호출
        1) 서로 다른 클래스 경우: 객체변수명.메소드명( );
        2) 같은 클래스 경우: this.메소드명( );
        3) 정적(static) 메소드인 경우: 클래스명.메소드명( );
    5. 지역변수: if/for/메소드 { } 내 매개변수/선언된변수 는 { } 밖에서 호출 불가능

[ 접근제한자 ]
    1. 서로 다른 클래스간 접근 여부, 캡슐화
    2. 종류
        public      : 프로젝트내 어디서든 호출/사용 
        private     : 현재 클래스내 호출/사용,  관례적으로 멤버변수는 private 한다.
        (default)   : 생략시, 같은 패키지내 호출/사용
        protected   :        같은 패키지내 호출/사용, 단) 상속 관계 예외
    3. 사용처: 클래스, 변수, 생성자, 메소드 등등
    
[ 주요 키워드 ]
    1. static: 인스턴스 없이 클래스내 변수 와 메소드 사용, 멤버변수 또는 메소드 사용
        *프로그램 시작시 메모리 할당 되고 프로그램 종료시 메모리 삭제*
    2. final: 초기화 이후에 수정불가능, *초기화필수 , 멤버변수 또는 메소드 사용
        * public static final 상수명 = 초기값 , 상수(const)
    3. setter and getter: 멤버변수가 private인 경우 간접접근(유효성검사) 제공 메소드 
        - set멤버변수명( ) : 저장 , get멤버변수명( ) : 호출
    4. toString( ): 인스턴스 호출시 주소값 대신에 문자열 반환 메소드
    5. 패키지: 해당 클래스가 위치한 경로/위치
    6. import: 다른 클래스 호출한 경우 .java파일 상단에 호출한 클래스의 패키지/경로 표시
        * 단) java.lang 패키지 제외( System, String, Math )한 다른 클래스인 경우

[ MVC패턴 ]
    1. 정의: 소프트웨어 개발에서 사용되는 디자인 패턴으로 세가지 주요 역할 분리하여 코드의 모듈화(조각)한다.
    2. 목적: 협업간의 코드와 파일들을 MVC패턴 따라 구성하여 효율성 높인다.
    3. 장점: 유지보수, 모듈화, 단일책임기능 (SRP: 단일 책임 원칙 - 객체지향 5대원칙(SOLID))등
    4. 단점: 분리함에 따라 관리 복잡도 높다.
    5. 사용처: 웹/앱 백엔드 프레임워크 사용
    6. 레이어/계층
        VIEW        : 입출력 담당, HTML/CSS/JSS/REACT/FLUTTER 등
        CONTROLLER  : model과 view 사이의 제어/로직/유효성검사/전달 담당, JAVA/PYTHON/NODE.JS
        MODEL       : 데이터관리 담당, JAVA/PYTHON/NODE.JS
    7. 이동객체
        DTO : 서로 다른 레이어/계층 간에 데이터 객체, setter, getter 지원
        VO  : 서로 다른 레이어/계층 간에 데이터 객체, getter 지원
    8. 흐름
        게시물쓰기:   view <--DTO/VO--> controller <--DTO/VO--> DAO/REPOSITORY <--> 데이터베이스(SQL)
        게시물조회:   view <--DTO/VO--> controller <--DTO/VO--> DAO/REPOSITORY <--> 데이터베이스(SQL)
    9. 패키지구성
        프로젝트폴더
            -> controller 폴더
            -> view 폴더
            -> model 폴더
                -> dao 폴더
                -> dto 폴더
            -> AppStart 클래스
