[ 데이터베이스 ] : 여러 사람이나 여러 프로그램들이 공유하여 사용할 수 있도록 데이터 집합
    - 데이터베이스 서버: MYSQL, 요청에 따라 데이터 처리하고 응답하는 프로그램
    - 특징: 실시간 접근, 동시공유, 데이터참조, 지속적인 변화
    - 종류: 1) 관계형 데이터베이스(SQL) 2) NOSQL
[SQL] : 관계형 데이터베이스 데이터를 조작/제어 하기 위한 표준 언어

    1) DDL 데이터정의어 : 데이터베이스/테이블 정의하고 변경 create~ , drop~ 
    2) DML 데이터조작어 : 테이블내 데이터들을 조작
    3) DCL 데이터제어어 : 데이터베이스 접근권한 / 계정관리 ROOT
    4) TCL 트랜잭션 제어어 : DML 실행 결과를 취소rollback/적용commit
    
[ 메타데이터 ]
    show databases;
    use 데이터베이스명;
    describe 테이블명;

[ DDL ]
    DROP : 
        drop database if exists 데이터베이스명;
        drop table if exists 테이블명;
    CREATE : 
        create database 데이터베이스명;
        create table 테이블명( 필드명 타입 제약조건 );
    ALTER : 
        alter table 테이블명 add 필드명 타입;
        alter table 테이블명 modify 필드명 새로운타입;
        alter table 테이블명 change 기존필드명 새로운필드명 새로운타입
    RENAME:
        rename table 테이블명 to 새로운테이블명;
    TRUNCATE: 
        truncate table 초기화테이블명;

[ 타입 ]
    정수 : tinyint , smallint , mediumint , int , bigint
        * unsigned : 부호 없는 자료, -128 ~ 127 -> 0 ~ 255
    실수 : float , double , decimal(문자열실수)
    날짜 : date , 시간: time , 날짜/시간: datetime
    문자열: char(n), varchar(n), text, longtext
        * char(3) : 고정의 3글자, [사][과][]
        * varchar(3): 가변의 3글자, [사][과]
        * longtext: 대용량
    논리: boolean(tinyint)

[ 제약조건 ]
    1. not null             : 값이 null 이면 레코드 등록 불가 
    2. unique               : 값이 중복 이면 레코드 등록 불가 
    3. default 기본값        : 레코드 등록시 값 생략하면 기본값 대입 
    4. auto_increment , primary key 인 경우만 사용가능* : 레코드 등록시 자동 증가 번호 대입 
    5. constraint primary key( PK필드명 ) : 기본키/식별키
    6. constraint foreign key( FK필드명 ) references 참조테이블명( PK필드명 ) : 외래키/참조키

[ 참조 옵션 ]
    1. on delete/update cascade   : PK가 삭제되면 FK 레코드도 같이 삭제 
    2. on delete/update restrict  :(생략시기본값) PK가 참조중이면 삭제 불가능 
    3. on delete/update set null  : PK가 삭제되면 FK 값은 NULL 


[ DML ] 
    1. insert into 테이블명( 필드명, 필드명 ) values( 값1, 값2);
        - insert into 테이블명 values( 값1, 값2, 값3 );         : 모든 필드에 값 대입시 필드명 생략가능
        - insert into 테이블명( 필드명 ) values( 값 ),( 값 );   : 2개 이상 레코드 등록
    2. select 필드명 from 테이블명 where 조건 
        - select * from 테이블명 : 테이블내 모든 필드의 레코드 조회
    2. update 테이블명 set 필드명 = 수정할값 , 필드명 = 수정할값 where 조건
    4. delete from 테이블명 where 조건 
    
[ 연산자 ]
    1. as: (별칭) 복잡한 필드명/테이블명을 간단하게 별명 만들기
        *  필드명 as 별칭 , 테이블명 as 별칭 , *주의할점: 생략가능 
    2. distinct: 조회결과 (필드값) 중복제거
    3. 산술연산자 : +더하기 -빼기 /나누기 *곱하기 div몫 mod나머지
    4. 비교연산자 : =같다 !=같지않다 >초과 <미만 >=이상 <=이하
    5. 논리연산자 : and이면서 or이거나 not부정
        * between 시작값 and 끝값 , * in( 값1 , 값2, 값3 )
    6. null연산자: 
        필드명 = null < 불가능 > 필드명 != null < 불가능 >
        필드명 is null < 가능 >  필드명 is not null < 가능 >
    7. 문자열패턴: 필드명 like "문자열패턴"
        % 모든문자대응      , 김%   : 김으로 시작하는 N글자 조회  
        _ 개수만큼문자대응  , 김_   : 김으로 시작하는 2글자 조회
